01 / TECHNOLOGY SNAPSHOT

A quick look at the landscape

A few common tools, grouped by the kind of work they help you do.

PROGRAMMING LANGUAGE

Python

A readable, general-purpose language often used for automation, data work, and back-end development.

  • Beginner-friendly syntax
  • Broad package ecosystem
  • Useful across many fields
PROGRAMMING LANGUAGE

JavaScript

The language of browser interactivity, also used on servers and across modern web applications.

  • Runs in every major browser
  • Front end and back end
  • Large developer community
WEB STANDARD

HTML & CSS

HTML gives web pages structure; CSS controls their visual presentation and responsive layouts.

  • Core web foundations
  • No build tools required to start
  • Essential for web design

02 / SIDE-BY-SIDE

Programming languages

A high-level overview. Each language can be used in more ways than shown here.

General characteristics of three popular programming languages
Language Often used for Getting started Runs in Notable strength
Python Automation, data, back-end services Gentle learning curve Python runtime Readable syntax and a broad ecosystem
JavaScript Interactive websites, web servers Easy to try in a browser Web browsers, server runtimes Native support across the web
Java Enterprise software, Android apps Structured, explicit foundations Java Virtual Machine Portability and mature tooling
C# Business software, games, web apps Guided tools and strong IDE support .NET runtime Versatile language and platform

There is no universal “best” language. Consider your project, interests, available tools, and the community you want to learn with.

03 / THE WEB TOOLKIT

How web technologies fit together

The browser combines different technologies to present and operate a web page.

Common web technologies and the roles they play
Technology Role Example Required to begin?
HTML Structures page content Headings, links, tables, forms Yes, for web documents
CSS Styles and lays out content Colors, spacing, responsive design Optional, but used for presentation
JavaScript Adds behavior and interactivity Menus, validation, dynamic content Optional for static pages
